## [2.2.0](https://github.com/opencloud-eu/web-extensions/releases/tag/external-sites-v2.2.0) - 2026-10-28

- Allow image icons for sites and dashboards [[#606](https://github.com/opencloud-eu/web-extensions/pull/606)]
- Allow named icons with a fill type and a color [[#606](https://github.com/opencloud-eu/web-extensions/pull/606)]

### 🐛 Bug Fixes

- Show dashboard icons like the app menu does [[#607](https://github.com/opencloud-eu/web-extensions/pull/607)]

- Show group-restricted sites and dashboards with OpenCloud Web 8.2.0 and later [[#650](https://github.com/opencloud-eu/web-extensions/pull/650)]
