## W95FA pixel font (`public/w95fa.woff2`, `public/w95fa.woff`)

"W95FA" is a recreation of the bitmap MS Sans Serif, the default Windows 95 UI
font. It is used here for the theme's `font-family`.

- Designer: Alina Sava (2019)
- License: SIL Open Font License, Version 1.1 (OFL-1.1)
  <https://openfontlicense.org/>
- The font files were obtained via the 95CSS project (see below). The font is
  free for personal and commercial use; it must not be sold on its own and is
  redistributed under the OFL.

## Windows 95 visual style (`public/win95.css`)

The beveled 3D borders, square corners, chunky scrollbars and general Windows 95
look are inspired by the 95CSS framework.

- 95CSS by Yoshi Mannaert: <https://github.com/yoshimannaert/95CSS>
- License: MIT, Copyright (c) 2019 Yoshi Mannaert

`public/win95.css` is an original implementation that hooks OpenCloud's own
`.oc-*` design-system classes and `--oc-role-*` tokens. It is not a copy of the
95CSS stylesheet; only the font is taken directly from that project.
